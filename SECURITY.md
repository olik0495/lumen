# Security

Found a way to harm Lumen users, or a weakness in Lumen, its updates or this website? Please tell me privately, not in public:

- **On GitHub:** the **Security** tab of this repository → **Report a vulnerability** (only I can read it), or
- **In Lumen:** the lightbulb in the title bar → **Bug**.

Please include what you did, what happened, and the Lumen version (Settings → General). I'll look into it and fix it in an update; you'll get credit in the release notes if you'd like.

## Getting Lumen safely

- Only download Lumen from this repository's [Releases](https://github.com/olik0495/lumen/releases) or the install line on [olik0495.github.io/lumen](https://olik0495.github.io/lumen). Anything offered elsewhere, or in a link someone sends you, is not Lumen.
- Lumen only installs updates signed with its own key, so a changed copy of an update is refused.
